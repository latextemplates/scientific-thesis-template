# Contributing to the scientific thesis template

Thank you for wanting to improve this template!
**Please do not send your pull request to this repository** — send it to the [LaTeX Template Generator (LTG)](https://github.com/latextemplates/generator-latex-template).

## The content of this repository is generated

Nearly everything you see here — the `.tex` sources, the preamble configuration, the examples, `Makefile`, `Texlivefile`, `Dockerfile`, `_latexmkrc`, `README.md`, and `.github/workflows/check.yml` — is **generated** from the micro-templates of the [LaTeX Template Generator](https://github.com/latextemplates/generator-latex-template).
This repository embeds the generator as a git submodule at `generator-latex-template/` and regenerates all variants in its `Update Files` workflow.

**A change made directly here is overwritten with the next regeneration.**

See [How the templates are generated](https://github.com/latextemplates/generator-latex-template/blob/main/CONTRIBUTING.md#how-the-templates-are-generated) for the workflow, and the generator's [CONTRIBUTING.md](https://github.com/latextemplates/generator-latex-template/blob/main/CONTRIBUTING.md) for how to add a package, an example, or a translation.

## What is maintained in this repository

- `CHANGELOG.md`
- `.github/workflows/update-files.yml`
- this file

Issues and questions about this template are welcome here — we move them to the generator if the fix belongs there.
If you are unsure where a change belongs: open an issue here and ask.

## Create a pull request

Create a pull request on GitHub.
For text inspirations, consider [How to write the perfect pull request](https://github.blog/2015-01-21-how-to-write-the-perfect-pull-request/).

You can add the prefix `[WIP]` to indicate that the pull request is not yet complete, but you want to discuss something or inform about the current state of affairs.
